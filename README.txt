
# Consulta de Signos

Aplicação web desenvolvida em PHP para identificar o signo zodiacal de um usuário com base em sua data de nascimento.

## Tecnologias utilizadas

- PHP
- HTML5
- XML
- Bootstrap 5
- CSS3
- JavaScript

## Funcionalidades

- Formulário para informar a data de nascimento.
- Validação da data informada.
- Leitura de informações através de arquivo XML.
- Identificação automática do signo zodiacal.
- Exibição do nome e descrição do signo.
- Tratamento de datas que atravessam a virada do ano.

## Estrutura do projeto

```text
Project/
├── assets/
│   ├── css/
│   └── js/
├── layouts/
│   └── header.php
├── index.php
├── show_zodiac_sign.php
└── signos.xml
```

## Como executar

1. Instale o XAMPP.
2. Copie o projeto para `C:\xampp\htdocs\Project`.
3. Inicie o Apache no XAMPP.
4. Acesse no navegador:

   http://localhost/Project/

Projeto acadêmico desenvolvido para praticar
desenvolvimento web utilizando PHP, HTML e XML.
